# Cars 'R Us

The project instructions for this single page app are to provide customers with a car building tool. The app displays options to design a car package, including paint color, interior, wheels, and technology. Then, after selecting the options, customers can place an order for the new car. 

After the order is submitted, the page re-renders to display the details from that new order at the bottom of the Custom Car Orders section.

The application was built using JavaScript, API fetch calls, and JSON server for data storage. Styles were done in CSS, including media queries to make the page look great on the smallest screen sizes.
